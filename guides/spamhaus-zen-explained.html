Spamhaus Zen Explained: What the World's Most-Used DNSBL Checks

Spamhaus Zen combines three Spamhaus lists in one query. Learn what SBL, XBL, and PBL each cover and how to interpret a Zen result.

What Zen is

Spamhaus Zen is a combined DNS blacklist that answers a single query with results from three Spamhaus lists: the Spamhaus Block List, the Exploits Block List, and the Policy Block List. Instead of querying three separate zones, a mail server makes one lookup against zen.spamhaus.org and reads the return code to learn which list, or lists, include the address. This combination is why Zen is one of the most widely used DNSBLs in the world. It is maintained by Spamhaus, a non-profit organisation that tracks spam and malware sources, and it is consulted by a large share of mail providers, including many that use it as a hard block rather than a soft spam score.

The SBL: spam sources

The Spamhaus Block List covers IP addresses and networks that Spamhaus has verified as sources of spam, or that host spam-related services such as spamvertised websites. An SBL listing usually means spam was actually sent from the address, or the address is part of a network that knowingly hosts spammers. SBL listings are evidence-based and manually verified in many cases, which is why mail providers trust them heavily. Removing an SBL listing requires fixing the spam source and submitting a removal request with evidence that the problem is resolved. Because SBL listings carry so much weight, an SBL entry alone can cause widespread delivery failures.

The XBL: exploited hosts

The Exploits Block List covers addresses that have been exploited by malware, including open proxies, machines infected with trojans, and systems participating in botnets. An XBL listing does not necessarily mean the owner sent spam deliberately; it often means a computer on that address was infected and used by someone else. The fix is to clean the infected machine, close the open proxy, and secure the network. XBL entries are often removed automatically once the exploitation stops, but a manual request can speed the process. If your address is on the XBL, treat it as a security incident, not just a delivery problem, and check every device on the network.

The PBL: policy listings

The Policy Block List is different from the other two. It lists address ranges that, according to the owning network's policy, should not be sending mail directly to the internet. This typically includes home broadband and dynamic IP ranges. A PBL listing does not mean you sent spam; it means your address is in a range that is not supposed to run a mail server. The correct fix is to send mail through your internet provider's smarthost or a reputable mail service instead of directly. End users can also request removal of a single static address if their provider allows it, but most home users should simply use their provider's outgoing server.

Reading a Zen result and acting on it

When you query Zen, the last octet of the returned address tells you which list matched: 127.0.0.2, 127.0.0.3, and similar codes map to SBL, XBL, and PBL entries, and combinations indicate multiple listings. Our checker reports the code so you can tell the difference. An SBL or XBL result means you need to find and fix a spam or security problem. A PBL result usually means you need to change how you send mail. In all cases, check the Spamhaus lookup page for the address, read the detail it provides, and follow its removal instructions. Do not ignore a Zen listing, because so many receivers use it that delivery problems will spread quickly if you leave it in place.

Frequently asked questions

Is Spamhaus Zen free to query?

Small-volume queries are free, but Spamhaus limits free use and asks heavy users to subscribe to its data feed. Our browser-based checker makes only a few queries per check.

How do I get removed from Zen?

Fix the cause, then use the Spamhaus Blocklist Removal Centre for the address. Each list type has its own guidance on that page.

Does Zen list whole networks?

Yes, in serious cases Spamhaus can list a network range. That is rare and usually follows sustained abuse that the network owner failed to stop.
