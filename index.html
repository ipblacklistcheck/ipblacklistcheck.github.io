IP Blacklist Checker

Enter an IP address or a domain. We check it against well-known public DNS blacklists and tell you, list by list, whether it is listed.

Indicative results, not a verdict. This tool queries a few well-known public DNSBLs from your browser using DNS-over-HTTPS. A full reputation check needs a dedicated service that covers many more lists, plus your mail logs and postmaster data. A clean result here does not guarantee delivery, and a listing here needs investigation before you act on it.

How it works: for an IP we reverse its octets and query each DNSBL via Google DNS-over-HTTPS (https://dns.google/resolve). For a domain we first resolve its A record, then check that IP. Barracuda may block unauthenticated queries; a timeout there means unknown, not clean.
